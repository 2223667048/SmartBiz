# SmartBiz 产品路线图

## 当前能力

- FastAPI 业务服务与浏览器工作台
- 企业账号、角色权限和租户数据隔离
- PostgreSQL RLS、pgvector 与 Alembic 迁移
- 文档异步索引、检索增强问答与来源引用
- Langflow 企业工作流和自定义业务工具
- 企业模型路由、用量计量、预算及订阅控制
- TLS、Prometheus、告警、备份和发布前检查

## 近期规划

1. 完善企业 SSO、细粒度 RBAC 和密钥托管。
2. 增加 OCR、复杂表格解析和大文件分片上传。
3. 建立索引版本切换、任务重放和批量迁移能力。
4. 完善供应商账单对账、成本告警和套餐策略。
5. 增加容量、故障恢复、安全和数据保留验证。

## 发布门槛

- 所有配置文件均通过 Compose 校验，数据库迁移版本一致。
- 租户隔离、RLS、权限撤销和限流测试全部通过。
- 备份可恢复，密钥不进入版本库或前端资源。
- Langflow 工作流、知识库检索和模型计量完成端到端验收。
- 公网部署完成域名、TLS、监控、告警及安全评估。
