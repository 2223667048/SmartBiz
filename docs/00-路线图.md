# 学习路径与验收条件（建议用 6 周，按实际进度调整）

第 1 周：理解 AI Agent 的模型、提示词、工具、记忆、知识库；运行 Langflow、建立最简单的 Chat Input → 模型 → Chat Output 工作流。验收：Playground 能稳定回答。

第 2 周：学会 API Key / FLOW_ID / HTTP 请求与响应；运行 SmartBiz 独立业务后台，分别测 mock 与 langflow。验收：浏览器聊天返回真实模型回复。

第 3 周：学习文档切分、embedding、检索与 RAG；在 Langflow 1.12 使用 Knowledge Bases 或安装需要的 Vector Store bundle。验收：针对虚构 FAQ 的测试问题回答不编造具体价格。

第 4 周：阅读源码执行链与 FastAPI 中间层；理解 session_id、持久化、工具调用。验收：解释 POST /api/chat 各函数如何串起来。

第 5 周：根据业务场景扩展“客户线索识别 + 留资 + 评价”，可使用 extensions/lead_intent.py 自定义组件。验收：能保存且管理受保护数据。

第 6 周：加鉴权、网关限流、HTTPS、审计、知识库权限、合规和灰度部署。验收：完成 README 中上线清单后，才允许外部试用。

# 故意不在第一阶段做的事
- 不直接修改 Langflow 内核和图执行引擎；先通过工作流和 API 扩展。
- 不以「支持多个公司」冒充已实现安全的多租户隔离。
- 不自动信任模型回答，不允许模型任意读写数据库或执行 SQL。
